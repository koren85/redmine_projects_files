# Результаты проверки — 15 ноября 2026

Проверка выполнена в отдельной облачной рабочей среде. Redmine на компьютере
пользователя не был доступен и не изменялся.

## Окружение

- Docker, официальный `redmine:4.1.7`.
- Ruby 2.6.10, Rails 5.2.6.3.
- PostgreSQL 13.23 (`postgres:13`).
- rubyzip 2.3.2.
- Браузер: Chromium, автоматизация Playwright.

## Интеграционные проверки

Запуск из корня Redmine:

```
RAILS_ENV=production bundle exec rails runner plugins/redmine_project_files/test/integration.rb
```

Последний запуск выполнен под пользователем процесса Redmine (`redmine`),
в собранном образе с плагином:

```
12 runs, 110 assertions, 0 failures, 0 errors, 0 skips
```

Проверены:

- Список, содержимое отдельного скачанного файла, запрет закрытой задачи
  и чужого проекта при обычном доступе.
- Дополнительное полное право, отключение модуля, отзыв права.
- Фильтры по проекту (ID и identifier), задаче, автору, группе, роли.
  Роль автора из другого проекта не даёт ложного совпадения.
- ZIP: содержимое, UTF-8-флаг, русское имя, отсутствие лишних файлов.
- Отказ для ZIP с чужим/закрытым/несуществующим ID, недопустимым значением ID.
- Пустой выбор, лимит числа файлов, лимит размера.
- Скачивание всех результатов фильтра.
- Все семь штатных типов источников вложений; исключение незавершённых загрузок.
- Отсутствующий файл на диске, удаление временного ZIP после передачи.
- Анонимный доступ, CSRF-проверка запроса ZIP.
- Два доступных проекта, пагинация 50 строк и ZIP со всех страниц.
- Получение права через членство в группе.
- Штатные страницы проекта, задачи, файлов проекта и скачивание вложения.

## Проверка интерфейса

В работающем Redmine с демонстрационными данными через Chromium выполнены:
вход, открытие каталога, выбор/снятие выбора всей страницы, скачивание ZIP
выбранных, применение фильтра задачи, ZIP всех результатов фильтра и
скачивание отдельного файла. Ошибок JavaScript не обнаружено.

ZIP из браузера проверены независимым Python zipfile: целостность CRC,
число файлов (3 и 1), UTF-8-флаг и русские имена.

## Границы проверки

Это проверка чистого Redmine 4.1.7 с PostgreSQL, а не существующей установки
пользователя. Совместимость с её настройками и сторонними плагинами, нагрузка
на её объёме данных и весь набор регрессионных тестов ядра не проверены.
Обещание абсолютного отсутствия ошибок эти проверки не дают.

Схема БД, исходные вложения и код ядра плагином не изменяются.
При сборке в облачной среде требовалось передать сертификат её HTTPS-прокси
как временный BuildKit secret. Проверка TLS не отключалась; сертификат
не включён в плагин или образ.
